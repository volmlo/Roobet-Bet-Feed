# roobet-feed

Headless-парсер ленты ставок Roobet (спортсбук = BetBy на sptpub.com) →
Telegram. Без браузера, без Tampermonkey: только два открытых API BetBy.

## Как это работает

1. `bets_feed` (`/api/v1/promo/bets_feed/...`) отдаёт последние ставки:
   сумма+валюта, коэффициент, игрок, тип, плечи (event_id, market_id,
   outcome_id, specifiers) — но **без названий**.
2. Снапшоты котировок (`/api/v4/live|prematch/...`, модуль `betby.ts`) по
   `event_id` дают спорт, команды, турнир и флаг `virtual`.
3. `descriptions.ts` берёт официальный словарь названий BetBy
   (`/api/v3/descriptions/brand/{brand}/markets/ru`) и подставляет в шаблоны
   исходов команды/тоталы/форы/порядковые. Тот же словарь, что рисует сайт, —
   названия точные и на русском. Свежий тянется на старте, офлайн-фолбэк —
   `data/markets.ru.json` в проекте.

Отсекается всё кибер/виртуальное (`desc.virtual`) и всё, кроме футбола,
баскетбола, тенниса и настольного тенниса.

## Каналы

- **основной** — ставки от `MAIN_MIN_USD` и коэффициента `MAIN_MIN_ODD`;
- **настольный теннис** — свои пороги `TT_MIN_*`; такие ставки идут и в свой
  канал, и в основной (пороги проверяются независимо);
- **прогрузы** — `CONSENSUS_N`+ одиночных ставок на один матч за окно.

## Запуск локально

```bash
npm install
cp .env.example .env      # вписать токен и id каналов
npm run decode            # печать ленты как её видит парсер, БЕЗ отправки
npm start                 # боевой режим
```

`npm run decode` — главный инструмент проверки: показывает восстановленные
названия исходов, ничего не отправляя. Сверять с сайтом перед запуском.

## Деплой на Raspberry Pi (pm2)

```bash
npm run pi:deploy         # перенести проект (tar по ssh)
# на Pi один раз: cd ~/roobet-feed && npm install && cp .env.example .env && nano .env
npm run pi:start          # pm2 start + save
npm run pi:logs           # хвост логов
```

Хост/каталог задаются переменными `DEPLOY_HOST` (по умолчанию
`pi@parser-pi.local`) и `DEPLOY_DIR` (`roobet-feed`).

Прокси (BetBy/Telegram) берётся из `PROXY_URL` — на Pi это локальный
HTTP-релей gost поверх SOCKS5, как в арбитражном проекте.

## Названия рынков

Берутся из официального словаря BetBy (2111 рынков) — те же, что на сайте:
тоталы, форы, 1x2, двойной шанс, обе забьют, тайм/сет/четверть, угловые,
точный счёт, комбо-рынки (1x2 и тотал и т.п.), досрочная выплата. Покрытие
живой ленты — полное. Если рынок вдруг незнаком (словарь не успел
обновиться) — честная заглушка «рынок N·исход M», а не выдумка.
